# Positioning in CSS

You need to figure out which selectors to use for this task yourself

## Task 1: Swap the places of Todo List and Todo List Icon in the sidebar

- Step 1: Set the position property of both the icon and the todo list text to `relative`
- Step 2: Move the icon right relative to its position and Move the text left relative to its position
- Step 3: Adjust the values until the Todo List text is on the left and the icon is on the right

## Task 2: Make the footer's position fixed in bottom left corner

### Scenario: As the footer is currently in the bottom of the page, you need to scroll down to see the footer. Change it so that the footer will appear in the bottom of the page no matter where we scroll

- Step 1: Set the position of the footer as fixed
- Step 2: Adjust the bottom, right, top and/or left property to fix the footer in the bottom left coerner

## Task 3: Absolute positioning a dropdown

### Scenario: The ... icon in the task card is supposed to be a dropdown button. When you click the icon an element is revaled with more options. The element that appears is supposed to be a dropdown menu and it should not occupy any space in the cards layout. You need to convert the element into a proper dropdown which should not interfer with the layout.

- Step 1: Convert the parent element of the dropdown-content into a positioned element (relative)
- Step 2: Conver the dropdown-content into a `absolute` positioned element
- Step 3: Adjust the left, right, top and/or bottom properties to fix the position of the dropdown
